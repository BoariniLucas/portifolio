1. Include `index.html`, `privacy-policy.html`, `sitemap.xml`, and `projects/controle-financeiro.html`.
2. Include the CSS, JavaScript, images, responsive image variants, favicons and other assets referenced by those pages or their styles and scripts. Preserve all relative paths, including resources referenced dynamically by JavaScript and the Open Graph image.
3. Exclude `.git/`, `.gitignore`, `AGENTS.md`, `README.md`, `dist/`, `.DS_Store`, backups, temporary files and `assets/img/contact/workspace.png`.
4. Before delivery, check the ZIP integrity and confirm that every local resource reference resolves to an included file. Confirm that `sitemap.xml` is at the archive root and that its URLs match the canonical URLs in the three pages.
